# 验收清单（建议按顺序操作一遍）

## 准备
- [ ] 双击 `start.bat`，浏览器自动打开 http://localhost:3000
- [ ] 控制台打印数据文件路径与局域网地址

## 基础资料
- [ ] 计量单位：能看到默认单位（件/箱/打/公斤/克/吨），可新增"提/袋"并设换算倍数
- [ ] 仓库：新增"仓库A""仓库B"，能编辑/停用
- [ ] 供应商：新增 1-2 家（含联系人/电话）
- [ ] 客户：新增 1-2 家
- [ ] 商品：新增商品，设置基准单位"件"、每件重量 0.5kg、进价/售价、低库存阈值 10

## 进货流程
- [ ] 新增进货单：选供应商/仓库/日期，明细录"5 箱 × 22 元"
- [ ] 保存后单号形如 CG20260826-0001，金额合计 110 元
- [ ] 库存查询：该商品库存 = 120 件，重量 = 60kg，平均成本 ≈ 0.92 元
- [ ] 库存流水出现"采购入库"记录，结存 120

## 出货流程
- [ ] 新增出货单：选客户，卖 30 件 × 1.5 元
- [ ] 保存后库存 = 90 件；毛利报表 = 销售额 45、毛利 17.5
- [ ] 库存流水出现"销售出库"记录

## 作废冲销
- [ ] 作废刚才的出货单 → 库存回到 120 件，流水出现"作废冲销"
- [ ] 作废进货单 → 库存归 0，平均成本归 0

## 库存调整与预警
- [ ] 库存调整 +50 件（原因：盘点）→ 库存 = 50
- [ ] 把商品低库存阈值设为 60 → 仪表盘低库存数 +1，库存页该行标红 ⚠

## 自定义字段
- [ ] 设置 → 自定义字段：给"商品"加字段"产地(文本)"，新建/编辑商品时可填可存

## 报表与导出
- [ ] 进货/出货/毛利报表可按时段统计，合计正确
- [ ] 商品、库存、流水、报表均可导出 Excel 并打开

## 导入与备份
- [ ] 商品管理 → 下载导入模板 → 填 2 行 → 导入 → 商品列表出现
- [ ] 设置 → 立即备份 → 备份列表出现文件，可下载
- [ ] 访问密码：设置后手机访问需登录；清除后恢复免登录

## AI 助手（只读 + 受控写入 + 经营分析）
- [ ] 设置 → AI 助手：填入 DeepSeek API Key，点「测试连接」成功
- [ ] 右下角 AI 按钮打开，问「主仓库现在有多少库存？值多少钱？」，回答带数据卡片、查询轨迹和时间口径
- [ ] 问一个不存在的商品/仓库，回答「没有查到」，不编数字
- [ ] 问「本月毛利是多少」，回答与报表统计一致
- [ ] 问「哪些货压着卖不动」，能列出滞销商品和库存金额
- [ ] 问「花椒最近进价有什么变化」，能列出历史进价和基准单价
- [ ] 问「这个月每天卖了多少」，能按日汇总销售额/毛利
- [ ] 问「哪个供应商进货最多」，能给出排名
- [ ] 只读状态下让 AI「进 5 件花椒」，AI 不会写库，并提示先授权
- [ ] 点顶部「只读」→ 按住 1.5 秒授权 → 顶部变成「可记账 14:59」
- [ ] 再让 AI 进 5 件花椒：出现待确认卡片；确认前库存不变
- [ ] 点「确认执行」后：生成单号、库存增加、出现自动备份提示
- [ ] 双击「确认执行」只生成一张单
- [ ] 生成第二个提案后点「取消」→ 库存不变
- [ ] 点「锁定」后再确认提案 → 被拒绝，提示重新授权
- [ ] 设置访问密码后，点权限按钮选「高风险」，输入密码 + 确认词「确认高风险」→ 顶部变成「高风险 04:59」
- [ ] 让 AI 作废刚才的测试单：卡片显示库存/成本影响；确认后单据变为已作废、库存回退
- [ ] 让 AI 修改测试单数量/价格：卡片显示新旧明细和合计；确认后单据更新
- [ ] 锁定高风险后再确认作废/改单 → 被拒绝
- [ ] 设置 → AI 操作记录能看到 proposed / confirmed / cancelled
- [ ] 关闭 AI 开关后，主系统其他功能正常；AI 面板给出明确提示
- [ ] 手机版：设置访问密码后登录，顶部「✨ AI」打开全屏助手，能查库存/毛利；未设密码时提示仅限本机
- [ ] 未设置访问密码时，从局域网另一台机器访问 AI 被拒绝，本机仍可用

## 数据安全
- [ ] 关闭启动窗口，`server/data/warehouse.db` 存在；重新启动数据不丢失
