# 验收清单（建议按顺序操作一遍）

## 准备
- [ ] 双击 `start.bat`，浏览器自动打开 http://localhost:3000
- [ ] 控制台打印数据文件路径与局域网地址

## 基础资料
- [ ] 计量单位：能看到默认单位（件/箱/打/公斤/克/吨），可新增"提/袋"并设换算倍数
- [ ] 仓库：新增"仓库A""仓库B"，能编辑/停用
- [ ] 供应商：新增 1-2 家（含联系人/电话）
- [ ] 客户：新增 1-2 家
- [ ] 商品：新增商品，设置基准单位"件"、每件重量 0.5kg、进价/售价、低库存阈值 10

## 进货流程
- [ ] 新增进货单：选供应商/仓库/日期，明细录"5 箱 × 22 元"
- [ ] 保存后单号形如 CG20260826-0001，金额合计 110 元
- [ ] 库存查询：该商品库存 = 120 件，重量 = 60kg，平均成本 ≈ 0.92 元
- [ ] 库存流水出现"采购入库"记录，结存 120

## 出货流程
- [ ] 新增出货单：选客户，卖 30 件 × 1.5 元
- [ ] 保存后库存 = 90 件；毛利报表 = 销售额 45、毛利 17.5
- [ ] 库存流水出现"销售出库"记录

## 作废冲销
- [ ] 作废刚才的出货单 → 库存回到 120 件，流水出现"作废冲销"
- [ ] 作废进货单 → 库存归 0，平均成本归 0

## 库存调整与预警
- [ ] 库存调整 +50 件（原因：盘点）→ 库存 = 50
- [ ] 把商品低库存阈值设为 60 → 仪表盘低库存数 +1，库存页该行标红 ⚠

## 自定义字段
- [ ] 设置 → 自定义字段：给"商品"加字段"产地(文本)"，新建/编辑商品时可填可存

## 报表与导出
- [ ] 进货/出货/毛利报表可按时段统计，合计正确
- [ ] 商品、库存、流水、报表均可导出 Excel 并打开

## 导入与备份
- [ ] 商品管理 → 下载导入模板 → 填 2 行 → 导入 → 商品列表出现
- [ ] 设置 → 立即备份 → 备份列表出现文件，可下载
- [ ] 访问密码：设置后手机访问需登录；清除后恢复免登录

## 数据安全
- [ ] 关闭启动窗口，`server/data/warehouse.db` 存在；重新启动数据不丢失
