# 轻进销存 LightStock

一个跑在自己电脑上的轻量进销存系统，面向个体经商户、小店铺和批发档口。数据保存在本机 SQLite 单文件中，浏览器打开即用；同一局域网内的手机也能开单、查库存、用 AI 助手。

> 设计取向：不做多租户、不做多用户账号体系，把「商品 → 进货 → 出货 → 库存 → 毛利 → 备份」这条主线做顺，让没有进销存经验的人也能直接上手。AI 默认只读；写入必须显式授权，并且每次都要人工确认。

## 功能一览

### 基础资料
- **商品**：名称、分类、规格、编号、条码、默认进价/售价、低库存阈值、备注；支持搜索、分类筛选、停用与恢复、Excel 批量导入导出。
- **供应商 / 客户**：联系人、电话、地址、备注；支持停用与恢复；可扩展自定义字段。
- **多仓库**：库存按仓库分别记账，仓库可新增、编辑、停用与恢复。
- **计量单位**：内置 件/箱/打/公斤/斤/克/吨；可自定义单位与换算倍数（如 1 箱 = 24 件），支持数量与重量两套体系，并可设置每单位重量。

### 进货 / 出货
- **采购入库单、销售出库单**：单号自动生成（`CG` / `XS` + 日期 + 流水号），明细支持多商品、多单位、单价、金额与行备注。
- **单位自动折算**：按所选单位录入，系统按换算倍数折算为基准单位入账，并自动计算总金额与总重量。
- **开单提速**：常卖商品快捷标签、上次成交价自动带出、快速新增供应商/客户、一键「再来一单」。
- **单据修改**：未作废单据可修改商品、数量、价格、日期和往来单位；修改采用红冲后重记，库存与成本同步更新。
- **作废冲销**：作废后库存自动冲回，保留完整流水痕迹；若冲销导致负库存会明确提示。
- **库存校验与成本**：销售出库校验库存是否充足；成本按移动加权平均计算，毛利报表使用实际结转成本。

### 库存
- **库存查询**：按仓库、商品关键词查询，支持「仅看低库存」；低库存与负数库存高亮提示。
- **库存修正（盘点）**：按单位增减库存并填写原因，自动写入库存流水。
- **库存流水**：按商品、仓库、类型、日期、关键词查询，覆盖采购入库、销售出库、库存调整、作废冲销。
- **库存金额**：展示当前结存、重量、平均成本与库存金额（高级模式）。

### 报表与仪表盘
- **仪表盘**：商品数、仓库数、库存总量/总值、今日进货/出货、低库存商品数；近 30 天进出货趋势、库存金额 Top 10、最近 20 条出入库流水。
- **报表统计**：进货报表、出货报表（可按商品/往来单位/日期汇总）、毛利报表（销售额、成本、毛利、毛利率）、库存报表。
- **Excel 导出**：商品清单、库存清单、进货明细、出货明细、库存流水、毛利报表。

### 简易 / 高级双模式
- **简易模式**：隐藏计量单位、自定义字段等进阶功能，只保留日常记账入口；商品表单可折叠「更多字段」。
- **高级模式**：开放全部功能，包括单位换算、自定义字段、独立仓库与库存流水菜单。
- 全新空库默认简易模式；已有业务数据的旧库默认高级模式。可随时在「设置」中切换，数据不受影响。

### 首次使用引导
- 首次打开自动弹出引导：选择界面模式、填写店铺与仓库名称、添加 3 个示例商品（每一步均可跳过）。
- 示例商品可一键清除；已产生进出货记录的商品会保留并给出提示。

### 手机端
- 同一局域网内用手机浏览器访问电脑 IP 即可使用；窄屏设备自动进入手机版，也可手动切换「电脑版 / 手机版」。
- 手机端提供：库存查询与低库存筛选、出货开单、修改/作废出货单、近 30 天出货单列表、全屏 AI 助手（顶部「✨ AI」，需先设置访问密码并登录）。

### 数据安全与备份
- **本地单文件**：SQLite + WAL，业务写入在同一事务内完成，库存与流水保持一致。
- **自动备份**：启动时自动备份，之后按设置间隔（默认 6 小时）备份，保留最近 30 份。
- **手动备份与恢复**：支持立即备份、下载备份、从服务器备份恢复，也可上传本机备份文件恢复（换电脑、硬盘损坏等场景）。
- **恢复保护**：恢复前自动另存当前数据库，并校验备份文件是否为有效备份；恢复后旧登录状态失效。
- **访问密码**：可设置单一口令，局域网访问时需登录。

### AI 助手（只读 + 受控写入 + 经营分析）

- **入口**：电脑端右下角悬浮按钮；手机端顶部「✨ AI」打开全屏助手。
- **查询与分析**：库存、库存金额、低库存、流水、单据、进货/出货/毛利报表；库存健康（负库存/零成本/未设售价/滞销）、历史进价、商品期间进出、供应商/客户排名、销售与毛利趋势。
- **默认只读**：AI 只能查数据，不能改任何东西。
- **可记账（15 分钟）**：点击 AI 面板顶部「只读」并按住确认后，AI 可以**提议**新建进货单、出货单、库存调整；提案只是一张待确认卡片，**确认前不写库**，确认时才调用现有业务服务执行，写前自动备份，并重新校验库存/价格是否变化。
- **高风险（5 分钟）**：作废/改单需要先设置访问密码，并在授权时输入确认词「确认高风险」；仍然每次都要在卡片上确认。作废不可撤销，改单采用红冲后重记。
- **数据可信**：所有数字来自受控的只读查询工具，回答同时展示服务端生成的数据卡片；查不到会明确说查不到；数据问题但模型没查数据时会显示警告。
- **审计**：查询、提案、确认、取消、失败都写入 `ai_audit_log`，设置页「AI 操作记录」可查。
- **模型**：默认 DeepSeek（OpenAI 兼容）；可用 `AI_API_KEY` / `DEEPSEEK_API_KEY` 环境变量，或在「设置 → AI 助手」填写。
- **Key 安全**：API Key 只保存在服务端（环境变量或 `server/data/ai.key` 独立文件），不写入数据库备份。
- **局域网保护**：未设置访问密码时，AI 对话/配置仅限本机；手机或局域网使用请先在设置中设置访问密码。
- **硬边界**：AI 永远不能恢复备份、改访问密码、改系统设置、删数据、执行任意 SQL；也不能改商品资料。

> 详细设计与权限/账号规划见 [AI 助手接入方案](docs/01_方案/2026-10-21_AI助手接入方案.md)，使用说明见 [AI 使用帮助](docs/ai-help.md)。

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | Vue 3、Element Plus、ECharts、Vue Router、Axios、Vite 6 |
| 后端 | Node.js、Express 4、better-sqlite3、xlsx |
| AI | DeepSeek / OpenAI 兼容接口、Function Calling 工具调用、openai SDK |
| 数据 | SQLite 单文件（`server/data/warehouse.db`，WAL 模式） |
| 部署 | Express 托管前端构建产物，单进程启动 |

## 快速开始

### Windows 一键启动
1. 安装 [Node.js](https://nodejs.org/)（20 或更高版本，推荐 LTS，安装时勾选 Add to PATH）。
2. 双击 `start.bat`。
3. 首次运行会自动安装依赖并构建前端（需联网），随后浏览器打开 <http://localhost:3000>。

关闭启动窗口即停止服务。首次启动会自动创建数据库、默认计量单位和「主仓库」。

### 手动启动

```bash
# 安装后端依赖
cd server
npm install
npm start           # http://localhost:3000
```

前端开发模式（热更新，`/api` 代理到 3000 端口）：

```bash
cd web
npm install
npm run dev         # http://localhost:5173
```

生产构建：

```bash
cd web
npm run build       # 产物输出到 web/dist，由后端直接托管
cd ../server
npm start
```

### 环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `PORT` | `3000` | 服务端口 |
| `LIGHTSTOCK_DATA_DIR` | `server/data` | 数据库与备份目录 |
| `AI_API_KEY` / `DEEPSEEK_API_KEY` | 空 | DeepSeek（或兼容服务）API Key；不设置时也可在设置页填写，保存到 `server/data/ai.key` |
| `AI_BASE_URL` | `https://api.deepseek.com` | OpenAI 兼容接口地址 |
| `AI_MODEL` | `deepseek-chat` | 支持工具调用的模型名 |

局域网访问地址会在服务启动时打印；若手机打不开，请检查电脑防火墙是否放行该端口。

## AI 助手配置

1. 启动服务，打开「设置 → AI 助手」。
2. 填入 DeepSeek API Key（或设置 `AI_API_KEY` / `DEEPSEEK_API_KEY` 环境变量），模型默认 `deepseek-chat`。
3. 点「测试连接」确认可用，再保存。
4. 需要手机端 AI 或高风险（作废/改单）时，先在「设置 → 基本设置」设置访问密码；设置后需要重新登录。
5. 电脑端点右下角 AI 按钮；手机端登录后点顶部「✨ AI」。

权限说明：

| 权限 | 时长 | 能做什么 | 怎么开启 |
|---|---|---|---|
| 只读 | 默认 | 查询、分析、报表 | 无需操作 |
| 可记账 | 15 分钟 | 提议进货/出货/盘点，逐次确认后执行 | 点顶部「只读」→ 按住确认 |
| 高风险 | 5 分钟 | 作废/改单，逐次确认后执行 | 必须有访问密码 + 输入「确认高风险」 |

AI 只能生成待确认提案；确认前不会写库，写入前自动备份。模型默认收到商品名、单据明细和备注，手机号会自动遮罩；备注里的地址等文本不会自动清除，敏感信息请先删掉。API Key 不写入数据库备份。

## 数据与备份

- 数据文件：`server/data/warehouse.db`（WAL 模式下还会有 `-wal` / `-shm` 文件）。
- 备份目录：`server/data/backups/`，保留最近 30 份。
- AI Key：`server/data/ai.key`（或在环境变量里），**不在 `warehouse.db` 里，也不会随数据库备份导出**；如果只迁移 `warehouse.db`，需要重新填写。
- 整个系统可只通过复制 `warehouse.db` 完成迁移；建议停机或先手动备份后再复制。
- 系统设置中可调整自动备份间隔、设置访问密码、执行备份与恢复。

## 关键设计

- **库存一致性**：所有出入库同时写 `stock_ledger` 流水与 `stock` 结存，并在同一事务内完成，异常自动回滚。
- **成本核算**：按流水顺序重放，维护移动加权平均成本；作废与修改通过红冲保证成本池正确。
- **负库存如实记账**：负数库存不会被自动抹平，而是作为账实不符的信号高亮提示。
- **单位换算**：单据按所选单位录入，后端按 `ratio` 折算基准单位入账；重量 = 数量 × 换算倍数 × 每基准单位重量。
- **自定义字段**：字段定义表 + 业务表 `custom_data` JSON 列，新增字段无需改表结构。
- **AI 数据可信**：模型只通过受控工具查询，SQL 由服务端参数化执行；前端同时渲染服务端数据卡片，避免模型口算/谎报。
- **AI 写入安全**：AI 只能生成提案，用户确认后才复用 `services/stock.js` 执行；确认时重新校验，写前备份，确认令牌不进模型上下文。
- **AI 权限**：默认只读；可记账 15 分钟；高风险 5 分钟（访问密码 + 确认词）；锁定/超时/重启即失效，全部审计。
- **前后端分离**：后端是纯 REST API + 静态文件托管，便于后续扩展桌面端和手机 App。

## 边界与扩展路线

当前版本定位为**单机、单用户**的轻量工具：

- 无多用户、账号与角色体系；访问密码只是统一入口口令，AI 的权限也只按浏览器会话来区分，不是账号权限。
- AI 默认只读；高风险（作废/改单）必须先有访问密码；AI 不能改商品资料、恢复备份、改访问密码、删数据、执行任意 SQL。
- AI 查询会把商品名、单据明细和备注发送给模型服务商；手机号自动遮罩，但备注里的地址等文本不会自动清除。
- AI 高级隐私模式（仅聚合/全量）、SSE 流式、回答反馈尚未实现；可选只读 SQL 暂不提供。
- 手机端目前提供库存查询、出货开单、单据和 AI 助手；进货、报表、设置等仍在电脑端完成。
- 不包含打印模板、发票、云同步等能力。

后续可扩展方向：

- **Windows 桌面端**：Tauri（推荐，安装包小）或 Electron 包装现有前端。
- **手机 App**：uni-app 复用 Vue 技术栈，对接同一套 REST API。
- **PWA**：手机浏览器「添加到主屏幕」，获得接近原生应用的使用体验。
