# 轻进销存 LightStock

一个跑在自己电脑上的轻量进销存系统，面向个体经商户、小店铺和批发档口。数据保存在本机 SQLite 单文件中，浏览器打开即用；同一局域网内的手机也能开单、查库存。

> 设计取向：不做多租户、不做复杂权限，把「商品 → 进货 → 出货 → 库存 → 毛利 → 备份」这条主线做顺，让没有进销存经验的人也能直接上手。

## 功能一览

### 基础资料
- **商品**：名称、分类、规格、编号、条码、默认进价/售价、低库存阈值、备注；支持搜索、分类筛选、停用与恢复、Excel 批量导入导出。
- **供应商 / 客户**：联系人、电话、地址、备注；支持停用与恢复；可扩展自定义字段。
- **多仓库**：库存按仓库分别记账，仓库可新增、编辑、停用与恢复。
- **计量单位**：内置 件/箱/打/公斤/斤/克/吨；可自定义单位与换算倍数（如 1 箱 = 24 件），支持数量与重量两套体系，并可设置每单位重量。

### 进货 / 出货
- **采购入库单、销售出库单**：单号自动生成（`CG` / `XS` + 日期 + 流水号），明细支持多商品、多单位、单价、金额与行备注。
- **单位自动折算**：按所选单位录入，系统按换算倍数折算为基准单位入账，并自动计算总金额与总重量。
- **开单提速**：常卖商品快捷标签、上次成交价自动带出、快速新增供应商/客户、一键「再来一单」。
- **单据修改**：未作废单据可修改商品、数量、价格、日期和往来单位；修改采用红冲后重记，库存与成本同步更新。
- **作废冲销**：作废后库存自动冲回，保留完整流水痕迹；若冲销导致负库存会明确提示。
- **库存校验与成本**：销售出库校验库存是否充足；成本按移动加权平均计算，毛利报表使用实际结转成本。

### 库存
- **库存查询**：按仓库、商品关键词查询，支持「仅看低库存」；低库存与负数库存高亮提示。
- **库存修正（盘点）**：按单位增减库存并填写原因，自动写入库存流水。
- **库存流水**：按商品、仓库、类型、日期、关键词查询，覆盖采购入库、销售出库、库存调整、作废冲销。
- **库存金额**：展示当前结存、重量、平均成本与库存金额（高级模式）。

### 报表与仪表盘
- **仪表盘**：商品数、仓库数、库存总量/总值、今日进货/出货、低库存商品数；近 30 天进出货趋势、库存金额 Top 10、最近 20 条出入库流水。
- **报表统计**：进货报表、出货报表（可按商品/往来单位/日期汇总）、毛利报表（销售额、成本、毛利、毛利率）、库存报表。
- **Excel 导出**：商品清单、库存清单、进货明细、出货明细、库存流水、毛利报表。

### 简易 / 高级双模式
- **简易模式**：隐藏计量单位、自定义字段等进阶功能，只保留日常记账入口；商品表单可折叠「更多字段」。
- **高级模式**：开放全部功能，包括单位换算、自定义字段、独立仓库与库存流水菜单。
- 全新空库默认简易模式；已有业务数据的旧库默认高级模式。可随时在「设置」中切换，数据不受影响。

### 首次使用引导
- 首次打开自动弹出引导：选择界面模式、填写店铺与仓库名称、添加 3 个示例商品（每一步均可跳过）。
- 示例商品可一键清除；已产生进出货记录的商品会保留并给出提示。

### 手机端
- 同一局域网内用手机浏览器访问电脑 IP 即可使用；窄屏设备自动进入手机版，也可手动切换「电脑版 / 手机版」。
- 手机端提供：库存查询与低库存筛选、出货开单、修改/作废出货单、近 30 天出货单列表。

### 数据安全与备份
- **本地单文件**：SQLite + WAL，业务写入在同一事务内完成，库存与流水保持一致。
- **自动备份**：启动时自动备份，之后按设置间隔（默认 6 小时）备份，保留最近 30 份。
- **手动备份与恢复**：支持立即备份、下载备份、从服务器备份恢复，也可上传本机备份文件恢复（换电脑、硬盘损坏等场景）。
- **恢复保护**：恢复前自动另存当前数据库，并校验备份文件是否为有效备份；恢复后旧登录状态失效。
- **访问密码**：可设置单一口令，局域网访问时需登录。

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | Vue 3、Element Plus、ECharts、Vue Router、Axios、Vite 6 |
| 后端 | Node.js、Express 4、better-sqlite3、xlsx |
| 数据 | SQLite 单文件（`server/data/warehouse.db`，WAL 模式） |
| 部署 | Express 托管前端构建产物，单进程启动 |

## 快速开始

### Windows 一键启动
1. 安装 [Node.js](https://nodejs.org/)（20 或更高版本，推荐 LTS，安装时勾选 Add to PATH）。
2. 双击 `start.bat`。
3. 首次运行会自动安装依赖并构建前端（需联网），随后浏览器打开 <http://localhost:3000>。

关闭启动窗口即停止服务。首次启动会自动创建数据库、默认计量单位和「主仓库」。

### 手动启动

```bash
# 安装后端依赖
cd server
npm install
npm start           # http://localhost:3000
```

前端开发模式（热更新，`/api` 代理到 3000 端口）：

```bash
cd web
npm install
npm run dev         # http://localhost:5173
```

生产构建：

```bash
cd web
npm run build       # 产物输出到 web/dist，由后端直接托管
cd ../server
npm start
```

### 环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `PORT` | `3000` | 服务端口 |
| `LIGHTSTOCK_DATA_DIR` | `server/data` | 数据库与备份目录 |

局域网访问地址会在服务启动时打印；若手机打不开，请检查电脑防火墙是否放行该端口。

## 数据与备份

- 数据文件：`server/data/warehouse.db`（WAL 模式下还会有 `-wal` / `-shm` 文件）。
- 备份目录：`server/data/backups/`，保留最近 30 份。
- 整个系统可只通过复制 `warehouse.db` 完成迁移；建议停机或先手动备份后再复制。
- 系统设置中可调整自动备份间隔、设置访问密码、执行备份与恢复。

## 测试

```bash
cd server
node test/all.js          # 综合 API 测试，默认端口 3200
node test/smoke.js        # 冒烟测试，默认端口 3100
node test/migration.js    # 成本算法迁移测试
```

> ⚠️ 测试脚本会写入甚至清空 `server/data/` 下的数据库（`migration.js` 会删除整个数据目录）。请勿在含真实数据的目录直接运行；先在项目副本中执行，或提前做好备份。

## 关键设计

- **库存一致性**：所有出入库同时写 `stock_ledger` 流水与 `stock` 结存，并在同一事务内完成，异常自动回滚。
- **成本核算**：按流水顺序重放，维护移动加权平均成本；作废与修改通过红冲保证成本池正确。
- **负库存如实记账**：负数库存不会被自动抹平，而是作为账实不符的信号高亮提示。
- **单位换算**：单据按所选单位录入，后端按 `ratio` 折算基准单位入账；重量 = 数量 × 换算倍数 × 每基准单位重量。
- **自定义字段**：字段定义表 + 业务表 `custom_data` JSON 列，新增字段无需改表结构。
- **前后端分离**：后端是纯 REST API + 静态文件托管，便于后续扩展桌面端和手机 App。

## 边界与扩展路线

当前版本定位为**单机、单用户**的轻量工具：

- 无多用户、角色与细粒度权限；访问密码只是简单的统一入口口令。
- 手机端目前聚焦库存查询与出货开单，进货、报表、设置等仍在电脑端完成。
- 不包含打印模板、发票、云同步等能力。

后续可扩展方向：

- **Windows 桌面端**：Tauri（推荐，安装包小）或 Electron 包装现有前端。
- **手机 App**：uni-app 复用 Vue 技术栈，对接同一套 REST API。
- **PWA**：手机浏览器「添加到主屏幕」，获得接近原生应用的使用体验。
